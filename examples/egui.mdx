`egui` is an immediate-mode GUI library for Rust, and `eframe` is its native application framework. Under the hood, eframe uses winit for window management — which means Linux requires the same GTK-thread workaround as the winit integration. On Windows and macOS, where eframe's internal winit loop and GTK are not in conflict, the tray icon can be created directly inside the `eframe::run_native` closure using `Rc<RefCell<Option<TrayIcon>>>` to bridge the ownership boundary.

## Integration approach

The egui integration splits into two code paths at compile time:

<CardGroup cols={2}>
  <Card title="Linux / FreeBSD" icon="linux">
    Spawn a `std::thread` that runs `gtk::init()` and `gtk::main()`. Create
    the `TrayIcon` inside that thread before calling `gtk::main()`. The GTK
    loop runs independently of eframe's winit loop.
  </Card>
  <Card title="Windows / macOS" icon="apple">
    Use `Rc<RefCell<Option<TrayIcon>>>` to move a clone into the eframe
    closure. Create the icon there once the `CreationContext` is available,
    keeping it alive for the duration of the app.
  </Card>
  <Card title="Polling events" icon="bell">
    Call `TrayIconEvent::receiver().try_recv()` inside `App::update` on every
    frame. Because egui redraws continuously this gives effectively real-time
    event processing without blocking.
  </Card>
  <Card title="No EventLoopProxy needed" icon="minus">
    Unlike winit/tao, eframe doesn't expose a typed `UserEvent` loop, so you
    poll the crossbeam channel directly rather than forwarding events through
    the event loop.
  </Card>
</CardGroup>

Add the following to your `Cargo.toml` to run this example:

```toml
[dev-dependencies]

```

## Full example

The example below is taken directly from the `tray-icon` repository
(`examples/egui.rs`).

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")] // hide console window on Windows in release

// On non-Linux platforms we use Rc<RefCell<...>> to pass the TrayIcon
// across the eframe closure boundary.
#[cfg(not(any(
    target_os = "linux",
    target_os = "dragonfly",
    target_os = "freebsd",
    target_os = "netbsd",
    target_os = "openbsd"
)))]
use std::{cell::RefCell, rc::Rc};

use eframe::egui;
use tray_icon::TrayIconBuilder;

fn main() -> Result<(), eframe::Error> {
    let path = concat!(env!("CARGO_MANIFEST_DIR"), "/examples/icon.png");
    let icon = load_icon(std::path::Path::new(path));

    // Since egui uses winit under the hood and doesn't use gtk on Linux, and we need gtk for
    // the tray icon to show up, we need to spawn a thread
    // where we initialize gtk and create the tray_icon
    #[cfg(any(
        target_os = "linux",
        target_os = "dragonfly",
        target_os = "freebsd",
        target_os = "netbsd",
        target_os = "openbsd"
    ))]
    std::thread::spawn(|| {
        use tray_icon::menu::Menu;

        gtk::init().unwrap();
        let _tray_icon = TrayIconBuilder::new()
            .with_menu(Box::new(Menu::new()))
            .with_icon(icon)
            .build()
            .unwrap();

        gtk::main();
    });

    // On non-Linux platforms, hold the TrayIcon in an Rc<RefCell<Option<...>>>
    // so it can be moved into the eframe closure while remaining accessible here.
    #[cfg(not(any(
        target_os = "linux",
        target_os = "dragonfly",
        target_os = "freebsd",
        target_os = "netbsd",
        target_os = "openbsd"
    )))]
    let mut _tray_icon = Rc::new(RefCell::new(None));
    #[cfg(not(any(
        target_os = "linux",
        target_os = "dragonfly",
        target_os = "freebsd",
        target_os = "netbsd",
        target_os = "openbsd"
    )))]
    let tray_c = _tray_icon.clone();

    eframe::run_native(
        "My egui App",
        eframe::NativeOptions::default(),
        Box::new(move |_cc| {
            // Create the tray icon inside the eframe closure on non-Linux platforms.
            // At this point the event loop is running and it is safe to create
            // native status bar items.
            #[cfg(not(any(
                target_os = "linux",
                target_os = "dragonfly",
                target_os = "freebsd",
                target_os = "netbsd",
                target_os = "openbsd"
            )))]
            {
                tray_c
                    .borrow_mut()
                    .replace(TrayIconBuilder::new().with_icon(icon).build().unwrap());
            }
            Ok(Box::<MyApp>::default())
        }),
    )
}

struct MyApp {
    name: String,
    age: u32,
}

impl Default for MyApp {
    fn default() -> Self {
        Self {
            name: "Arthur".to_owned(),
            age: 42,
        }
    }
}

impl eframe::App for MyApp {
    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        use tray_icon::TrayIconEvent;

        // Poll the tray event channel on every frame.
        // try_recv() is non-blocking and returns Err(TryRecvError::Empty) when idle.
        if let Ok(event) = TrayIconEvent::receiver().try_recv() {
            println!("tray event: {event:?}");
        }

        egui::CentralPanel::default().show(ctx, |ui| {
            ui.heading("My egui Application");
            ui.horizontal(|ui| {
                let name_label = ui.label("Your name: ");
                ui.text_edit_singleline(&mut self.name)
                    .labelled_by(name_label.id);
            });
            ui.add(egui::Slider::new(&mut self.age, 0..=120).text("age"));
            if ui.button("Click each year").clicked() {
                self.age += 1;
            }
            ui.label(format!("Hello '{}', age {}", self.name, self.age));
        });
    }
}

fn load_icon(path: &std::path::Path) -> tray_icon::Icon {
    let (icon_rgba, icon_width, icon_height) = {
        let image = image::open(path)
            .expect("Failed to open icon path")
            .into_rgba8();
        let (width, height) = image.dimensions();
        let rgba = image.into_raw();
        (rgba, width, height)
    };
    tray_icon::Icon::from_rgba(icon_rgba, icon_width, icon_height).expect("Failed to open icon")
}
```

## Running the example

From the repository root:

```sh
cargo run --example egui
```

<Note>
  `TrayIconEvent::receiver().try_recv()` will only receive events if you have
  **not** called `TrayIconEvent::set_event_handler(Some(...))`. The two
  mechanisms are mutually exclusive — registering a handler disables the
  channel. In the egui pattern the channel is the right choice since there is no
  accessible `EventLoopProxy` to forward events through.
</Note>

<Tip>
  To also handle menu events in your `App::update`, add a matching poll for
  `MenuEvent::receiver()`:

  ```rust
  use tray_icon::menu::MenuEvent;

  if let Ok(event) = MenuEvent::receiver().try_recv() {
      println!("menu event: {event:?}");
  }
  ```
</Tip>
