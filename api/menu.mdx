`tray_icon::menu` is declared as `pub use muda::*`, meaning it re-exports the entire [`muda`](https://docs.rs/muda) crate verbatim. You do not need to add `muda` as a direct dependency — everything is available through the `tray_icon::menu` path. This page documents the key types from that re-export that are used when building context menus for tray icons.

```rust
use tray_icon::menu::{Menu, MenuItem, MenuEvent, PredefinedMenuItem, AboutMetadata};
```

<Note>
  This page documents only the types used directly in tray-icon examples.
  `tray_icon::menu` re-exports the complete `muda` crate, which includes
  additional menu types such as `Submenu`, `CheckMenuItem`, and
  `IconMenuItem`. See the full API reference at
  [docs.rs/muda](https://docs.rs/muda) for the complete type inventory.
</Note>

## Menu

`Menu` is the top-level container for a context menu. It implements the
`ContextMenu` trait, which is required by `TrayIconBuilder::with_menu`.

### Construction

```rust
let tray_menu = Menu::new();
```

`Menu::new()` returns an empty menu with no items.

### Adding Items

<ParamField path="menu.append_items(items)" type="&[&dyn IsMenuItem] -> Result<()>">
  Appends multiple items at once. This is the method used in the tray-icon
  examples — it accepts a slice of references to any type that implements
  `IsMenuItem`.

  ```rust
  tray_menu.append_items(&[
      &PredefinedMenuItem::separator(),
      &quit_item,
  ]).unwrap();
  ```
</ParamField>

### Cloning and Attaching

`Menu` implements `Clone`, so you can build it before the event loop starts
and then clone it when attaching to the tray icon inside `StartCause::Init`:

```rust
let tray_menu = Menu::new();
// … populate tray_menu …

// Later, inside the event loop's init handler:
TrayIconBuilder::new()
    .with_menu(Box::new(tray_menu.clone()))
    .build()
    .unwrap();
```

## MenuItem

`MenuItem` represents a standard clickable entry in a menu.

### Construction

<ParamField path="text" type="&str" required>
  The label displayed in the menu.
</ParamField>

<ParamField path="enabled" type="bool" required>
  Whether the item is interactive. Pass `false` to render the item greyed out.
</ParamField>

<ParamField path="accelerator" type="Option<Accelerator>">
  An optional keyboard shortcut shown alongside the label. Pass `None` if no
  accelerator is needed.
</ParamField>

```rust
use tray_icon::menu::MenuItem;

let quit_item = MenuItem::new("Quit", true, None);
```

### Identifying Clicked Items

```rust
quit_item.id() // -> &MenuId
```

`id()` returns a reference to the item's `MenuId`. Compare this against the
`id` field of a `MenuEvent` to determine which item was activated:

```rust
if event.id == quit_item.id() {
    // The "Quit" item was clicked.
}
```

## PredefinedMenuItem

`PredefinedMenuItem` provides common menu entries whose behaviour is
implemented natively by the OS where possible.

### `separator()`

Inserts a visual horizontal rule between groups of items:

```rust
PredefinedMenuItem::separator()
```

No parameters. Returns a `PredefinedMenuItem` that renders as a non-clickable
divider line.

### `about(text, metadata)`

Inserts an About entry. On macOS this triggers the standard About panel.

<ParamField path="text" type="Option<&str>">
  Custom label for the menu entry. Pass `None` to use the platform default
  (typically "About \<app name\>").
</ParamField>

<ParamField path="metadata" type="Option<AboutMetadata>">
  Metadata displayed in the About panel. Pass `None` for an empty panel.
</ParamField>

```rust
PredefinedMenuItem::about(
    None,
    Some(AboutMetadata {
        name: Some("My App".to_string()),
        copyright: Some("Copyright © 2024 My Company".to_string()),
        ..Default::default()
    }),
)
```

### Other Predefined Items

The following predefined items are also available. On Linux they require the
`libxdo` feature (enabled by default):

| Method | Description |
|---|---|
| `PredefinedMenuItem::copy(text)` | Copy to clipboard |
| `PredefinedMenuItem::cut(text)` | Cut to clipboard |
| `PredefinedMenuItem::paste(text)` | Paste from clipboard |
| `PredefinedMenuItem::select_all(text)` | Select all text |

<Tip>
  On Linux, `Copy`, `Cut`, `Paste`, and `SelectAll` require the `libxdo`
  feature and the `libxdo` system library (`libxdo-dev` on Debian/Ubuntu,
  `xdotool` on Arch). The `libxdo` feature is included in tray-icon's default
  feature set. Install the system package before building:

  ```sh
  # Debian / Ubuntu
  sudo apt install libxdo-dev

  # Arch Linux / Manjaro
  pacman -S xdotool
  ```
</Tip>

## AboutMetadata

`AboutMetadata` is a plain struct with all-optional fields that populate the
About dialog shown by `PredefinedMenuItem::about`.

```rust
use tray_icon::menu::AboutMetadata;

let meta = AboutMetadata {
    name: Some("My App".to_string()),
    version: Some("1.0.0".to_string()),
    copyright: Some("Copyright © 2024".to_string()),
    authors: Some(vec!["Alice".to_string()]),
    comments: Some("An example application.".to_string()),
    license: Some("MIT OR Apache-2.0".to_string()),
    website: Some("https://example.com".to_string()),
    website_label: Some("example.com".to_string()),
    icon: None,
    ..Default::default()
};
```

All fields are `Option`-typed. Fields you leave as `None` are omitted from
the panel or filled with OS defaults.

## MenuEvent

`MenuEvent` is fired whenever a menu item is clicked. It mirrors the design of
`TrayIconEvent`: you can consume events from a channel receiver or register a
custom handler.

### Fields

| Field | Type | Description |
|---|---|---|
| `id` | `MenuId` | The ID of the menu item that was activated. Compare with `MenuItem::id()` to identify the source item. |

### Channel Receiver

```rust
use tray_icon::menu::MenuEvent;

let menu_channel = MenuEvent::receiver();

// Inside your event loop:
if let Ok(event) = menu_channel.try_recv() {
    println!("Menu item clicked: {:?}", event.id);
}
```

`MenuEvent::receiver()` returns a `&MenuEventReceiver` (a
`crossbeam_channel::Receiver<MenuEvent>`). This receiver will not produce
events if a custom handler has been set via `set_event_handler`.

### Custom Event Handler

```rust
use tray_icon::menu::MenuEvent;

// Forward menu events into a winit/tao EventLoopProxy:
let proxy = event_loop.create_proxy();
MenuEvent::set_event_handler(Some(move |event: MenuEvent| {
    proxy.send_event(UserEvent::MenuEvent(event));
}));
```

<ParamField path="f" type="Option<F> where F: Fn(MenuEvent) + Send + Sync + 'static">
  Pass `Some(closure)` to install a handler; pass `None` to clear it and
  resume delivery to the channel receiver.
</ParamField>

## ContextMenu Trait

`ContextMenu` is the trait required by `TrayIconBuilder::with_menu`. You pass
a `Box<dyn ContextMenu>` so the builder is not tied to a specific menu type.

```rust
TrayIconBuilder::new()
    .with_menu(Box::new(tray_menu))
    // ...
```

`Menu` implements `ContextMenu`, so wrapping it in `Box::new` is all that is
needed. The trait is also object-safe, enabling dynamic dispatch.

## Complete Example

The following example builds a menu with an About entry, a separator, and a
Quit item; attaches it to a tray icon; and handles both tray and menu events
using the `tao` event loop — matching the pattern in the official
`examples/tao.rs`.

```rust
use tao::{
    event::Event,
    event_loop::{ControlFlow, EventLoopBuilder},
};
use tray_icon::{
    menu::{AboutMetadata, Menu, MenuEvent, MenuItem, PredefinedMenuItem},
    TrayIconBuilder, TrayIconEvent,
};

enum UserEvent {
    TrayIconEvent(TrayIconEvent),
    MenuEvent(MenuEvent),
}

fn main() {
    let event_loop = EventLoopBuilder::<UserEvent>::with_user_event().build();

    // Forward tray events into the event loop.
    let proxy = event_loop.create_proxy();
    TrayIconEvent::set_event_handler(Some(move |event| {
        proxy.send_event(UserEvent::TrayIconEvent(event));
    }));

    // Forward menu events into the event loop.
    let proxy = event_loop.create_proxy();
    MenuEvent::set_event_handler(Some(move |event| {
        proxy.send_event(UserEvent::MenuEvent(event));
    }));

    // Build the context menu.
    let tray_menu = Menu::new();
    let quit_i = MenuItem::new("Quit", true, None);
    tray_menu.append_items(&[
        &PredefinedMenuItem::about(
            None,
            Some(AboutMetadata {
                name: Some("tao".to_string()),
                copyright: Some("Copyright tao".to_string()),
                ..Default::default()
            }),
        ),
        &PredefinedMenuItem::separator(),
        &quit_i,
    ]).unwrap();

    let mut tray_icon = None;

    event_loop.run(move |event, _, control_flow| {
        *control_flow = ControlFlow::Wait;

        match event {
            // Create the tray icon once the event loop is running.
            Event::NewEvents(tao::event::StartCause::Init) => {
                let icon = tray_icon::Icon::from_rgba(vec![255u8; 4 * 32 * 32], 32, 32).unwrap();
                tray_icon = Some(
                    TrayIconBuilder::new()
                        .with_menu(Box::new(tray_menu.clone()))
                        .with_tooltip("tao - awesome windowing lib")
                        .with_icon(icon)
                        .build()
                        .unwrap(),
                );
            }

            Event::UserEvent(UserEvent::TrayIconEvent(event)) => {
                println!("{event:?}");
            }

            Event::UserEvent(UserEvent::MenuEvent(event)) => {
                println!("{event:?}");

                if event.id == quit_i.id() {
                    tray_icon.take();
                    *control_flow = ControlFlow::Exit;
                }
            }

            _ => {}
        }
    });
}
```
