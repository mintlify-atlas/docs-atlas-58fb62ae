`tray-icon` lets you create system tray icons for desktop applications written in Rust. It provides a clean builder API for configuring the icon, attaching a context menu, and listening to mouse events — all on Windows, macOS, and Linux (via GTK).

## Quick Example

The snippet below creates a tray icon with a context menu. `Icon` must be constructed before calling `build` — for example via `Icon::from_rgba` or by loading image bytes.

```rust
use tray_icon::{TrayIconBuilder, Icon, menu::Menu};

// Icon can be loaded from RGBA bytes: Icon::from_rgba(rgba_data, width, height)
let icon = Icon::from_rgba(vec![0u8; 32 * 32 * 4], 32, 32).unwrap();

let tray_menu = Menu::new();

let tray_icon = TrayIconBuilder::new()
    .with_menu(Box::new(tray_menu))
    .with_tooltip("My Application")
    .with_icon(icon)
    .build()
    .unwrap();
```

<Note>
  On macOS, the tray icon **must** be created on the main thread and only after the event loop is already running — not merely created. On Linux and FreeBSD, a GTK event loop must be running on the **same thread** on which the tray icon is created, so when using a non-GTK windowing library (such as winit) you typically run the GTK loop on a separate thread and create the tray icon there.
</Note>
